# Algorithm Engineering

Mein Repository für die Vorlesung Algorithm Engineering an der FSU Jena im Wintersemester 2026/27.

## Ordner

- `answers/` Antworten zu den Exam Assignments und die kleinen Coding-Aufgaben
- `project/` C++ Projekt
- `paper/` Paper (4 Seiten) zum Projekt
- `slides/` Folien der Vorlesung

## Bewertung

- Antworten und Coding-Aufgaben: 40 %
- Projekt: 40 %
- Paper: 20 %

Abgabe ist am 1. März 2027.
